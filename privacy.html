YouTube Shorts Bot

개인정보처리방침

‘YouTube Shorts Bot’(이하 이 도구)은 유튜브 채널 1분경제(@1min_Eco) 운영자가 직접 만들어 혼자 쓰는 개인용 도구예요. 이 도구는 YouTube API 서비스를 사용해요. 이 도구를 쓰는 것은 YouTube 서비스 약관에 동의하는 것이고, Google이 데이터를 다루는 방식은 Google 개인정보처리방침을 따라요.

누구의 데이터를 다루나요

운영자 본인의 Google 계정과 유튜브 채널만 다뤄요. 다른 사람이 이 도구로 로그인하는 일은 없고, 다른 사람의 계정 데이터는 받지 않아요.

어떤 데이터에 접근하나요

  • 채널 기본 정보: 채널 이름·채널 ID와 구독자 수 같은 채널 전체 수치. 올바른 채널에 로그인했는지 확인하는 데 써요.
  • 영상 정보: 운영자가 올리는 영상 파일과 제목·설명·태그·공개 상태. 영상을 올리는 데 써요. 올린 영상을 이 도구로 고치거나 지우지는 않아요.
  • 채널 통계: 조회수, 시청 시간, 시청 지속률 같은 집계 수치(읽기 전용). 다음 영상을 다듬는 데 써요.

이 도구는 댓글, 구독자 개인 정보, 메일, 연락처, 결제 정보에는 접근하지 않아요.

어디에 저장하나요

로그인 토큰은 운영자의 PC에 파일 하나로만 저장하고, 운영자 계정만 읽을 수 있게 권한을 막아 두어요. 토큰을 다른 서버나 클라우드에 올리지 않아요. 통계는 필요할 때 받아서 보고, 지금은 파일로 따로 남기지 않아요. 남기게 되면 이 방침에 먼저 적어요.

누구와 공유하나요

Google 사용자 데이터를 팔거나, 광고에 쓰거나, 다른 사람에게 넘기지 않아요. 다만 영상 기획을 위해 운영자가 쓰는 AI 도우미(Claude 등)에 조회수 같은 집계 수치를 보여 줄 수는 있어요. 운영자 본인의 작업을 위한 것이고, 집계 수치에는 시청자 개인을 알아볼 수 있는 정보가 없어요. 이 도구가 Google API로 받은 정보를 쓰고 옮기는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따라요.

쿠키

이 도구와 이 안내 사이트는 쿠키를 쓰지 않아요. 이 사이트는 GitHub Pages에 올려 두었고, GitHub가 접속 기록을 남길 수 있어요(GitHub 개인정보처리방침).

접근 끊기와 삭제

운영자는 언제든 Google 계정의 앱 권한 페이지에서 이 도구의 접근을 끊을 수 있어요. 접근을 끊으면 이 도구는 더 이상 계정에 접근하지 못해요. PC의 토큰 파일만 지워도 도구는 접근하지 못하지만 Google 쪽 허가는 남아 있으니, 권한 페이지에서도 끊어 주세요.

Privacy Policy (English summary)

YouTube Shorts Bot is a personal tool built and used only by the operator of the YouTube channel 1분경제 (@1min_Eco). It uses YouTube API Services. By using it, you agree to the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy.

Data accessed: only the operator's own Google account and YouTube channel: channel name, ID and channel-level totals such as subscriber count (to confirm the right channel), the operator's video files and their title, description, tags and privacy status (to upload videos; the tool does not edit or delete uploaded videos), and aggregate channel analytics such as views, watch time and audience retention (read-only, to improve future videos). It does not access comments, subscriber personal data, email, contacts or payment information.

Storage: the OAuth token is stored only as a file on the operator's own PC, readable only by the operator's user account, and is never uploaded to other servers or cloud services. Analytics are fetched when needed and are not currently saved to files; if that changes, this policy will be updated first.

Sharing: Google user data is never sold, used for advertising, or shared with anyone. The operator may show aggregate figures such as view counts to an AI assistant (such as Claude) used for planning videos; this serves only the operator's own work, and aggregate figures contain no information that identifies individual viewers. YouTube Shorts Bot's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies: neither the tool nor this site uses cookies. This site is hosted on GitHub Pages, which may keep access logs.

Revoking access and deletion: access can be revoked at any time on the Google security settings page. Revoking access stops all access. Deleting the token file also stops the tool, but the Google-side grant remains until it is revoked on that page.

Changes: changes to this policy are posted on this page with a new date.

Contact: GitHub issues.
